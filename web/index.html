用直播姬开播（千音出画面）

B站对千音这条网页开播通道要求人脸认证，直播姬那条通道不用。这个模式不碰 B站开播接口：千音把「游戏画面 + 皮套 + 字幕」合成好开成一个窗口，直播姬直接采集它，开播由直播姬点。

未开启
  1. 先在上方选好游戏窗口和声音输出设备，再点「开启源画面」。
  2. 直播姬 → 添加素材 → 窗口采集 → 选「千音源画面」；采到黑屏就把采集方式换成 WGC。
  3. 直播姬的画布/直播设置改成 1920×1080，和源画面窗口一样大；缩放选「适配」，别选「拉伸填满」，否则画面会再糊一次。
  4. 直播姬的音频选系统声音，只采一次：源画面窗口本身无声，游戏声和千音配音由系统声音采集；不要再对这两个进程重复采音。
  5. 在直播姬点「开始直播」。这时千音的「开始直播」会被挡住，避免重复推流。
  6. 源画面窗口没有标题条（留着会被直播姬一起播进画面），要关它在千音里点「关闭源画面」。

固定回复

  

    弹幕命中关键词时，不经过 AI，直接念你写好的回复（多行=随机选一行，可用 {name} {text}）。

    固定回复不受“回复概率”和“触发词”限制，即使关掉了弹幕 AI 回复也照样生效；但仍受屏蔽词和同一观众冷却限制。从上到下匹配，命中第一条就停。

    匹配方式：包含 = 弹幕里有任意一个关键词（逗号分隔）；完全一致 = 弹幕正好等于某个关键词；正则 = 关键词按正则表达式匹配。

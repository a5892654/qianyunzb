# 办公室玩法与鲨总动作

新增玩法是鲸语自己的扩展，默认启用；在「AI 设置 → 上班摸鱼 → 办公室玩法」可分别开关。节目预览运行时才计时，暂停后投票、任务、道具和动画一起暂停。

## 观众怎么参与

| 玩法 | 弹幕 | 画面和结果 |
| --- | --- | --- |
| 打掩护 | 摸鱼期间发「老板来了」，随后发 1/2/3 或「装开会 / 疯狂打字 / 打小报告」 | 默认 10 秒预警。两种掩护票合计多于举报票则逃过罚款；否则被抓。无人参与也会被抓。无论是否躲过，本轮摸鱼仍白干。关闭打掩护开关后恢复直接查岗。 |
| 离谱需求 | 「鲨总派活」「派任务」「离谱需求」，随后发 1/2/3 | 默认每 180 秒自动派一次，也可手动请求；35 秒内投票决定应对办法。按真实选择结算工资与经验，AI 根据结果接话。无人投票不扣工资。 |
| 公共道具 | 「兑换咖啡」后「使用咖啡」等 | 参与每轮投票首次获得 1 公共积分，改票不重复获得。同直播间共享积分与道具，初始 5 分。 |
| 临时守则 | 「改员工守则」「守则投票」，随后发 1/2/3 | 先投票 15 秒，选出禁说“老板/鲨总”、每句最多五字、禁说“哼/才不是”之一。默认执行 30 秒；只检查真正播出的主播台词，不检查观众原话。每轮最多罚 60 工资，守住规则奖励 80。 |
| 升职与还债 | 正常工作、完成任务和成功打掩护 | 获得经验并升职。负工资进入还债状态，还清时有专属反应。积分、经验、库存和累计还债进度保存在 `wage_state.json`，跨日保留。 |

同一时间只开一个投票；加薪投票也会占用投票位置。查岗遇到已有投票时等待当前轮结束再给打掩护窗口，避免覆盖票数。非查岗的手动活动有 30 秒冷却。任务与守则选项平票时使用靠前的选项。

## 八种摸鱼小剧场

自动摸鱼保持每工作 1–3 分钟随机触发一次，暂停不计时。每轮从八种情景中轮换抽取，全部抽完再洗牌，避免连续重复。弹幕「摸鱼」随机选择，也可用下列指令指定；摸鱼进行中不会被新指令覆盖。

| 内容 | 指定弹幕 | 屏幕与神态 |
| --- | --- | --- |
| 偷偷看番 | 看番 / 追番 | 海底番剧画面，转头看屏幕 |
| 刷短视频 | 刷短视频 / 刷视频 | 视频计数与手机卡片，低头偷看 |
| 逛购物车 | 逛购物车 / 逛网店 | 零食、键盘、鱼抱枕的购物清单 |
| 偷吃零食 | 偷吃零食 / 吃薯片 | 零食补给画面，轻轻歪头 |
| 假装开会 | 假装开会 | 四人假会议，一本正经抬头 |
| 偷偷打盹 | 打个盹 / 偷睡 | 月亮屏保，低头闭眼，结束后睁眼 |
| 偷玩小游戏 | 偷玩游戏 / 打小游戏 | 像素钓鱼小画面，专注看屏幕 |
| 工位发呆 | 发呆 | 云朵与小鱼，抬头放空 |

画面均为本地绘制的节目道具，不打开网站、不下单、不播放外部视频。AI 的主动吐槽、弹幕回应和查岗借口会收到当前情景；生成期间情景已结束或换轮时丢弃过期的摸鱼台词。查岗、白干、罚款、道具和救场机制沿用原有规则；查岗投票中的「装开会」仍优先作为掩护投票，不会切换成开会情景。设置页可选择情景并点「模拟观众喊摸鱼」测试。

## 道具效果与价格

| 道具 | 公共积分 | 效果 |
| --- | --- | --- |
| 咖啡 | 3 | 20 秒内额外 +1.5 手速，仍受手速上限限制；重复使用不会叠加或刷新。 |
| 挡箭牌 | 5 | 抵消下一次查岗罚款，本轮仍白干。待用状态可随存档保留，用掉后消失。 |
| 坏键盘 | 3 | 25 秒内代码显示器出现错字与报错；只是节目道具，不执行任何代码。 |
| 枕头 | 3 | 60 秒内下一次安全结束的摸鱼奖励 30 工资；被抓不会领到奖励。 |

单种库存最多 9 件。积分不足不购买，库存不足不使用。已使用的咖啡、坏键盘、枕头属于短时效果，重启不续跑；未使用的库存保留。

重启后不续跑未完成的投票或临时守则，也不对未完成的活动结算罚款。

## 长线进度

完成每轮工作 +10 经验，成功打掩护 +40，成功任务 +80，守住临时守则 +20，完成一天工资目标 +300。每个节目工作日首次还清倒欠工资额外 +100。

职级为实习生（0）、正式员工（300）、组长（900）、经理（1800）、临时老板（3000）。首次升到临时老板的当天可以反过来给鲨总派活，跨日成为资深经理，经验不清零。

## 鲨总素材

使用内置 imagegen，以已有全身墨镜鲨总为角色参考，单独生成四张全身动作图并制作透明 GIF。每张都是独立角色图，不是宫格图。

- `web/assets/shark-boss-inspect.png` / `.gif`：抱臂、低头查岗。
- `web/assets/shark-boss-assign.png` / `.gif`：拿任务板、派离谱需求。
- `web/assets/shark-boss-angry.png` / `.gif`：叉腰、张嘴训话。
- `web/assets/shark-boss-approve.png` / `.gif`：竖拇指、拿批准证书。
- 原有 `shark-boss-fullbody.gif` 和 `shark-boss-fullbody-idle.gif` 保留。

对应 `.prompt.txt` 保存完整生图提示词。重建动画运行 `.venv\Scripts\python.exe tools\build_shark_boss_gif.py`。GIF 只在首次使用时解码，最多缓存三套动作；在查岗、任务、失败和升职时自动切换。

直播取景采用右侧大近景，裁去素材透明留白后放大，头部与主播接近大小；主播在鲨总出场时向左让位，扣薪牌避开脸部。全身 PNG/GIF 原文件保留不变。可在摸鱼设置中调整「鲨总出场大小」（默认 1，范围 0.6–1.5）。只缓存最多 48 张已放大的动作帧，避免整套大图反复缩放和无限占用内存。

鲨总与肥鱼均在桌后，桌面遮住下半身。肥鱼公皮默认开启「工作时敲键盘」：双手、手腕和手指交替敲击，键盘随角色站位移动；手速越高，敲击越快。摸鱼和挨训会停手，说话手势优先，手势结束后恢复敲击，暂停则保持当前动作。其他皮套缺少这套手臂参数时不会强行启用。

## 精装修与鲨总音效

办公室背景使用内置 imagegen 生成，保存为 `web/assets/wage-office-premium.png`，完整提示词在同名 `.prompt.txt`。蓝金墙板、海景窗与暖光书架为背景插画；工资面板、显示器、代码、皮椅、桌面、键盘、手账和鱼形马克杯由程序叠加。人物位置、反手修复和敲键盘动作沿用已验收的半身工位取景。背景与静态桌面只初始化一次，缺少新背景时仍可显示原蓝色工位。

`web/assets/wage-sfx/` 包含五段原创短音效：探头查岗、抓包训话、派活、发怒和批准。用本机 Windows 中文 SAPI 合成「歪比、巴布、哇啦」等无意义音节，再加入低音变调、滑音和原创脚步/弹簧/纸张/提示音，没有采样游戏或网上表情包音频。运行 `tools/build_wage_sfx.py` 可离线重建，素材说明与时长记录在 `manifest.json`。

音效由独立事件队列与混音通道播放，不等待 AI/TTS、不驱动肥鱼口型。主播说话时音效降为原来的 25%；音乐也会暂时降低，避免削弱对白。每次最多一段、最长三秒，默认音量 45%、最短间隔三秒，过期事件直接丢弃；同时发生时抓包训话优先。只有当前播放类型为摸鱼且预览运行、节目未暂停时才自动播放。暂停、停止预览、切换游戏或关闭音效会停止自动音效。设置中可选择五种声音试听，试听不改工资或玩法进度，沿用「声音输出设备」。修改 Python 后需重启工具加载新音效服务。

「一键开播」选择「上班摸鱼」后，播放类型下方直接显示「鲨总声音」开关，与设置页同步并保存。关闭会立刻停止当前音效（包括试听），再次开启只响应之后的新事件；肥鱼语音和背景音乐继续播放。

## 验证脚本

- `tools/verify_wage.py`：原有摸鱼功能和路由验证。
- `tools/verify_wage_office.py`：新增玩法、投票冲突、道具交易、实际播音检查、跨日存档和动作切换。
- `tools/verify_wage_ui.cjs`：设置保存和八个模拟按钮，所有服务请求均为离线替身。
- `tools/preview_wage_office.py`：用已有本机皮套帧生成六种玩法合成样图。
- `tools/verify_wage_audio.py`：音效资产、独立队列、冷却、暂停/开关、路由校验、混音与语音时钟。
- `tools/preview_wage_polish.py`：复用已验收真实 Live2D 帧，合成精装修场景与五种音效试听视频，不连接直播账号。
- `tools/verify_wage_slack.py`：八种情景轮换、指定弹幕、暂停、查岗上下文、动态屏幕与过期台词验证。
- `tools/preview_wage_slack.py`：合成八种摸鱼情景的真实皮套预览视频和总览图。

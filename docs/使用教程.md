# 使用教程

> 适用于 WhaleTalk v0.1.0（Windows）。名字对不上时，以软件界面为准。

## 一、它能做什么

连接你的 B 站直播间，实时读取进房、弹幕、礼物、上舰、醒目留言（SC）、关注、点赞，
交给 Qoder 大模型生成回复（也可以只用模板），再用本机 GPT-SoVITS 合成语音播放：

| 事件 | 默认反应 |
|---|---|
| 进房 | “欢迎小王、阿花和新朋友来到直播间！”（短时间内多人合并成一句） |
| 弹幕 | AI 针对内容回复 |
| 礼物 | “谢谢老板甲的人气票……”（连击合并成一次） |
| 上舰 | 隆重感谢上船 |
| 醒目留言 | 先感谢，再回应留言内容 |
| 关注 / 点赞 | 简短感谢（点赞默认关闭） |

另外：Live2D 皮套（自动呼吸眨眼、对口型、按情绪换表情、头顶气泡），点歌，OBS 歌单与字幕。

## 二、文件说明

| 文件 | 说明 |
|---|---|
| `WhaleTalk.exe` | 主程序，双击运行 |
| `qoder_login.bat` | 登录 Qoder CLI（AI 回复要用） |
| `config.json` | 设置文件，首次运行自动生成，**含登录信息，不要外传** |
| `logs/app.log` | 程序日志 |
| `logs/gsv_engine.log` | 由本程序启动的 GPT-SoVITS 引擎日志 |
| `qoder_workdir/` | Qoder 会话工作目录（空目录，不用管） |

## 三、第一次使用

1. **登录 Qoder**：双击 `qoder_login.bat`，浏览器里点确认。
   不想用 Qoder：在【AI 设置】切到“OpenAI 兼容 API”，填地址、模型名、Key。
2. **启动**：双击 `WhaleTalk.exe`，会出现黑色控制台窗口（关掉它 = 退出程序）和软件界面窗口。
   程序会自动启动语音引擎、连接直播间、预热 AI；引擎首次启动约 20~60 秒。
3. **设置音色**（否则没有声音）：
   - GPT-SoVITS 目录、参考音频（3~10 秒干净人声）、参考音频文本（一字不差）
   - 没有自己的模型就用默认预训练权重；自己训练的模型放进 `GPT_weights*` / `SoVITS_weights*` 后点“刷新列表”
   - 点【试听】确认声音
4. **登录 B 站**（强烈建议）：【直播间 / 登录】→【扫码登录】。
   不登录也能收弹幕，但观众名字会被打码，AI 叫不出名字。
5. **测试**：【控制台】右下角“模拟测试”，不需要真实观众就能听效果。

## 四、界面

### 控制台
- 顶部：直播间状态、B 站账号、AI、语音引擎、是否暂停
- 按钮：连接/断开、暂停/恢复、跳过当前语音、清空队列
- 左栏：直播间消息（灰色 = 被跳过，后面写了原因）
- 右栏：AI 回复（内容、来源、耗时、表情）
- 手动发言：“直接念” / “让 AI 说”

### 回复规则
每种事件独立设置：启用、AI/模板、模板（多行随机）、AI 提示。
模板变量：`{name}` `{text}` `{gift}` `{num}` `{value}` `{guard}` `{price}`。

弹幕额外可设：冷却秒数、回复概率、触发词、忽略表情包、先念原弹幕。
进房/关注/点赞可设：同人冷却、合并窗口、一次最多念几个名字。
进房默认开启「送过礼物的观众单独暖心欢迎」：例如“欢迎小明回来呀！你的心意我一直记着，今天也要一起开开心心！”可修改专属模板和 AI 提示，沿用进房的 AI/模板模式与同人冷却。普通观众仍使用普通欢迎；同时进房的送礼观众会逐人欢迎。按直播间和 UID 保存记录，改名、重启后仍能识别；从程序实际收到的礼物开始记录，免费礼物也算，模拟事件不算，无法追溯未接收的历史礼物。
礼物可设：连击合并、付费礼物最低价值、是否感谢免费礼物。
默认开启「按数量和价值丰富感谢（token 口粮）」：先点名感谢送礼观众，并说「谢谢老板，这能买不少token了」。达到 5 / 20 / 100 个礼物，或总价值 10 / 50 / 200 元时，逐档增加感谢、比心和祝福；连击以合并后的数量和总价值计算。AI 模式会润色补充感谢，模板模式或 AI 失败时使用对应档位的完整文案。关闭此选项后使用自定义模板和 AI 提示。
全局：屏蔽词、忽略名单、队列上限、最长等待、名字长度。
「主动和观众聊天」默认开启：最近 5 分钟有真实进房、弹幕或礼物活动，冷场 20 秒后会结合近期聊天和游戏局势找话题，默认每 60 秒最多主动聊一次。可调整等待时间和间隔。新观众消息优先；暂停、断线、切房或告别下播时不再主动聊天。模拟事件不会触发此功能，近期活动只表示可能有人在场，不是实时在线人数。

主动聊天会轮换游戏体验、日常生活和轻松闲聊等话题，交替使用分享、感慨和提问。系统会参考近期已播台词和同类互动回复；重复的主动话题直接轮换备用文案，每次只生成一次，不为改写措辞额外等待一轮。新弹幕会优先打断尚未生成完的后台闲聊。

连续接话会参考本场已播出的提问，以及同一 UID 观众最近几轮的留言和回复。观众回答后顺着聊两到四轮；没人回答或话题聊完时自然收尾，不催促观众重复回答。这些聊天记录只保留在本次连接的短期记忆里，切房、断线和超时会清理。

游戏解说会参考真实掉血、回血、头目登场、已确认的胜负和实际获得的遗物作出反应，不把尚未领取的奖励当作已到手。保持边玩边聊，不额外增加解说冷却；紧张时用短句，模型漏写、重复或跑题时用简短解说补上。重要变化优先于普通解说，排队太久的重要反应会作废。

主动聊天按设置的间隔触发，不附加随机等待或战斗间隔倍率，也不会因为低血量或头目战一直禁止开口；观众弹幕优先回应。

「定时提醒关注 / 点赞」默认开启，间隔 3 分钟自然提醒一次，例如“喜欢这个直播间的话，点个关注呀，下次还来一起玩！”。可以单独关闭、修改间隔（至少 60 秒）、AI 提示和轮换备用文案；AI 失败、重复或漏掉提醒时使用备用文案。观众消息优先，提醒排队播放；间隔从实际播报开始计算，不附加战斗或随机等待。使用本机推流时，弹幕安静也会提醒；使用其他推流方式时，需最近 5 分钟内有真实观众活动。暂停、断线、切房或告别下播时停止，切房重新计时。

优先级：醒目留言 = 上舰 > 礼物 > 弹幕 = 关注 > 进房 = 游戏重要反应 > 点赞 = 主动互动 > 普通游戏解说。

### 固定回复
弹幕命中关键词 → 直接念固定内容，不消耗 AI。

- 关键词逗号分隔；匹配方式：包含 / 完全一致 / 正则
- 回复每行一条随机选，可用 `{name}` `{text}`
- 可指定表情；从上到下匹配，命中第一条即停
- 不受回复概率/触发词限制；关掉弹幕 AI 回复也生效；仍受屏蔽词和冷却限制

### 点歌
默认免费：观众发 `点歌+歌名`（如 `点歌+晴天`）→ 自动搜索网易云排队播放。也支持全角加号、冒号和空格。开启“点歌需要先送礼物”后才要求先送指定礼物拿券；旧配置若仍要求送礼，取消勾选即可。
送插队礼物：排队中的歌立刻置顶；还没点歌则下一首点的歌直接置顶。
详情见 [README 的点歌一节](../README.md#点歌)。

### 直播姬定时下播
千音登录同一个主播账号后，设置“播多久自动停播”的分钟数即可，后台会自动检测直播姬开播、自动计时，到点结束B站直播间并核对平台状态。无需手动启动倒计时；能读取本场开播时间时，软件重启后也按原时间计算，否则从首次检测开播算起。告别语音失败或超时仍会继续停播，设为 0 或点击“关闭自动停播”即可停用。按每天固定时间停播：在“每日定时直播”选“直播姬 / OBS：仅定时停播”，填停播时间并保存启用，无需在千音预览或开播。请保持千音运行；退出会取消当前任务，再次启动后按已保存时长恢复监测。结束的是B站直播间，不退出直播姬程序。

时长倒计时和每日定时停播都会提前约 30 秒播报“停播前说的话”，留空时使用默认告别语。结束词优先播放，告别期间暂停其他待播回复和游戏解说。语音正常时等待原定时刻停播；语音尚未说完时先等播放结束，避免最后几个字被截断。

### AI 设置
- Qoder：模型可一键列出并切换；会话常驻会记得上下文，“每多少句重开会话”控制记忆长度
- 人设：决定主播性格与语气
- 每次回复最多字数：越短越快，直播建议 30~50

### 语音设置
启用语音、引擎目录/地址、GPT 与 SoVITS 权重、参考音频与文本、语言、
语速、表现力、采样步数（嫌慢改 16 或 8）、音量、输出设备。

### Live2D 皮套
- 模型目录与文件、大小与位置、呼吸、眨眼、头部摆动、口型与幅度
- 常驻表情（眼镜、发型等配件）
- 情绪 → 表情/动作映射表，所有表情动作都能一键试播
- 气泡：位置、字号、宽度、配色、停留时间
- 皮套上镜：勾上后「一键开播」会把皮套合成进直播画面（角落 + 大小 + 边距），
  取景和表情沿用本页设置，不用另开窗口或 OBS。合成时气泡不画进画面。

### 直播主题

侧边栏打开【直播主题】，点击【蓝色海洋】即可将直播画面整体换成蓝色海底布景：左侧为真实弹幕与礼物消息，皮套以半身取景叠在左下角，右侧显示游戏，底部是「深海电台」点歌条。也可从【一键开播 → 皮套上镜 → 直播主题】进入。

「深海电台」条会自动显示正在播放的点歌：《歌名》· 歌手、播放进度和点播观众；观众点歌切歌时亮出「已切换电台」，右侧常驻「发送『点歌+歌名』」提示和随音乐跳动的声形条。没有播放音乐时恢复滚动公告；关闭点歌后隐藏电台操作提示。

房间名称、欢迎语、底部公告和弹幕开关会自动保存；【角色取景】从 1（全身）到 3 调节，默认 2（半身）。【调整皮套】可继续拖动或缩放角色，海洋主题的位置、大小和取景独立保存。点击【原始画面】恢复原来的全幅游戏与皮套布局。

未启动游戏预览时，主题页展示布局示意和已启用的本机皮套；点击【查看游戏实际预览】选择游戏窗口并开始预览，即可检查真实游戏、弹幕和皮套。预览、千音源画面及直接推流同步换肤；开启游戏预览后也可直接回主题页查看实时画面。请先在【Live2D 皮套】中选择并启用自己的模型。

### OBS 字幕 / 点歌列表
分别是 `/overlay` 与 `/songs` 两个浏览器源地址。

## 五、让观众听到声音

程序默认用系统默认扬声器播放。直播软件开启“电脑声音/桌面音频”采集即可。
如果你戴耳机而直播软件只采集麦克风，观众听不到；可安装虚拟声卡（如 VB-Cable）并在这里选择。

## 六、常见问题

**回复全是模板？**
看“AI 回复”里的来源与原因，多为 Qoder CLI 未登录 → 运行 `qoder_login.bat`。

**没声音？**
引擎是否“在线”、参考音频是否选、音量为 0、输出设备是否正确。

**观众名字是“新朋友”？**
未登录 B 站时名字被打码；扫码登录即可（也可在规则里关掉这个替换）。

**B 站登录显示无效？**
看控制台提示；`-101 账号未登录` 表示 Cookie 过期。手动粘贴时至少要有 `SESSDATA`。

**点歌放的不是原唱？**
原版无版权或需 VIP 时会找相似版本；登录网易云 VIP 后可放原版。

**歌太吵盖过说话？**
点歌页调小音乐音量，或把“说话时音乐压低到”调到 20%。

**关掉程序画面还留着？**
新版会自动隐藏（正常退出立即，强制结束 ≤5 秒）；仍残留就刷新直播软件里的浏览器源。

**双击提示已在运行？**
程序只允许一个实例，会直接打开界面。彻底退出请点左下角“退出程序”或关掉黑色控制台窗口。

**想换直播间？**
【直播间 / 登录】改房间号 →“保存并重连”。

**想训练自己的音色？**
用 `tools/train_voice.py`（见 README）。

## 七、注意事项

- 只使用你有权使用的声音做参考音频，不要克隆他人声音；直播时建议说明是 AI 合成
- 点歌播放的音乐版权归权利人所有，公开播放需遵守平台规范
- `config.json` 里有登录 Cookie，不要发给别人
- 第三方组件与素材的许可见 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)
